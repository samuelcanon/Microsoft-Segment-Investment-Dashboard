# Microsoft's Steady Margin Hides a 21 Point Gap Between Its Segments
Microsoft reports one operating margin. In FY2024 it was 44.6%, and it looks stable. Look closer, the fastest growing segment is not the most profitable one, which makes the next place to allocate money to become unclear. That is why this ends in three different recommendations rather than one.

***This is a decision focused BI dashboard that turns public financial data into a allocation recommendation, with the analysis kept visible in Python.***
